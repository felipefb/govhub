# Registro de riscos — GovHub AI

| Risco | Impacto | Mitigação |
|-------|---------|-----------|
| IA inventar capacidade, preço ou atestado | jurídico/reputacional crítico | rastreabilidade obrigatória + QA Agent + gates humanos |
| Envio automático indevido | inabilitação, sanção | sistema não envia nada; envio é ato humano registrado |
| Comportamento anticoncorrencial | infração à ordem econômica | proibição no prompt de todos os agentes + auditoria |
| Vazamento entre tenants | LGPD, contratual | isolamento por tenant + testes de aceite obrigatórios |
| Fonte oficial fora do ar | perda de oportunidade | múltiplas fontes, alertas operacionais, quarentena |
| Certidão vencida em certame | inabilitação | alertas de validade + rebaixamento automático no GovReady |
| Success fee mal estruturado | risco fiscal/jurídico | estruturação jurídica prévia, transparência contratual |
| Conflito de interesse hub × fornecedores próprios (Avintis/Favon) | reputacional | Avintis/Favon como fornecedores cadastrados comuns; governança separada |
