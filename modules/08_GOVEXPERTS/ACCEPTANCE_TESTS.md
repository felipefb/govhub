# Testes de aceite — GovExperts

1. Todo encaminhamento remunerado deve ser transparente para o cliente.
2. Especialista não verificado não pode receber encaminhamentos.
3. Avaliação deve estar vinculada a um engajamento real.
4. Registro com fonte ausente deve ser rejeitado ou colocado em quarentena.
5. Toda saída de IA deve guardar fonte, documento, trecho, data, modelo, versão do prompt, confiança e aprovador.
6. Usuários de tenants diferentes não podem acessar os mesmos artefatos privados.
7. Ação crítica sem aprovação humana registrada deve ser bloqueada.
